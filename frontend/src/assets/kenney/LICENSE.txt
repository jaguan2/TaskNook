Credit is not required, but appreciated: assets by Kenney (kenney.nl).

They are the pre-rendered isometric views shipped with the kit, used as-is:
  bedDouble_*   -> the "bed" item        (SW = rot 0, SE = rot 1)
  loungeSofa_*  -> the "sofa" item       (SE = rot 0, SW = rot 1)
  loungeChair_* -> the "armchair" item   (SE = rot 0, SW = rot 1)
  cabinetBed_*  -> the "nightstand" item (SW = rot 0, SE = rot 1)
