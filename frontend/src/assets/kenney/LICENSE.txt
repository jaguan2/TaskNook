The PNG renders in this folder come from Kenney's "Furniture Kit"
(https://kenney.nl/assets/furniture-kit), licensed CC0 1.0 Universal
(public domain — https://creativecommons.org/publicdomain/zero/1.0/).

Credit is not required, but appreciated: assets by Kenney (kenney.nl).

They are the pre-rendered isometric views shipped with the kit.
Modifications (palette remaps, shading preserved): bedDouble_* has its
duvet recoloured warm white; the *_orange/_cream/_rose/_blue/_sage files
are fabric-recoloured "colourways" of the same renders, generated by
remapping the fabric hue band (bed: hue 2–28° & sat>0.25; sofa/chair:
hue 5–30° & sat>0.45, which leaves the wooden base untouched) while
keeping each pixel's lightness so the three-face shading survives.

Mapping to TaskNook items (r0 = the render used at rot 0, r1 at rot 1):
  bedDouble_*            -> bed            (SW / SE)  [duvet recoloured]
  loungeSofa_*           -> sofa           (SE / SW)
  loungeChair_*          -> armchair       (SE / SW)
  cabinetBed_*           -> nightstand     (SW / SE)
  chairRounded_*         -> chair          (SE / SW)
  bookcaseOpen_*         -> shelf          (SE / SW)
  bookcaseClosedWide_*   -> bookcase       (SE / SW)
  sideTableDrawers_*     -> sidetable      (SW / SE)
  radio_*                -> radio          (SE / SW)
  kitchenFridgeSmall_*   -> fridge         (SW / SE)
  tableRound_*           -> cafetable      (SE / SW)
  kitchenBar_*           -> counter, and the base of coffeecounter (SE / SW)
  kitchenCoffeeMachine_* -> coffeecounter's top layer (SE / SW)
  cabinetTelevision_*    -> tvunit's base (SE / SW)
  televisionVintage_*    -> tvunit's top layer (SE / SW)
  desk_*                 -> desk's base (SE / SW)
  laptop_*               -> desk's top layer (SW / SE)
  tableCoffee_*          -> coffeetable (SE / SW)
  lampRoundFloor_*       -> floorlamp (SE / SW; TaskNook adds its own glow)

Everything in this folder is bundled by an import.meta.glob in
components/IsoItems.jsx — keep only files a manifest row uses.
